Summaries

Handling biological replicates in long-read RNA sequencing data by joining or not joining

This study compares pooling reads before transcript reconstruction with reconstructing each replicate before merging annotations, across six tools and two sequencing platforms. Its results offer practical guidance for multi-sample long-read RNA-seq: the best strategy depends on the tool and whether novel isoform discovery or scaling to many replicates is the priority.

vitals 0.4.0: expanded agent evaluation from R

The vitals release adds interfaces for comparing custom R agents with coding agents, along with helpers for reading evaluation logs back into R. These capabilities support systematic testing of analysis assistants and inspection of their behavior on research tasks.

Positron September release: data import and package vulnerability scanning

Positron's September release adds a code-generating data import dialog, expanded data connections, package vulnerability scanning, and improvements to environment setup. The updates can simplify routine R/Python analysis while making data-loading steps easier to reproduce.

orbital 0.7.0 expands in-database prediction for tidymodels

orbital 0.7.0 and tidypredict 1.2.0 extend translation of fitted models into equations for prediction inside databases, adding support for methods such as discriminant analysis, neural networks, and partial least squares. This gives research teams more options for scoring large tables without moving them into an R session.

Gradient-based optimization for mRNA sequence design

ID3 optimizes mRNA codon choices through continuous probability distributions while constraining the encoded amino acid sequence. The computational framework combines RNA accessibility and codon-adaptation objectives, with code and reproduction scripts available for evaluating its usefulness in sequence-design workflows.

ViSTA learns mutation-aware DNA representations for breast cancer subtyping

ViSTA trains a DNA language model on variant-centered tumor-exome sequences to predict breast cancer subtypes and examine subtype-associated sequence patterns. The study illustrates a mutation-aware representation strategy for cancer genomics; its reported classification results do not establish clinical diagnostic utility.

ellmer 0.5.0 adds document handling and web-search citations

ellmer 0.5.0 extends its R interface to language models with document inputs, file uploads, web-search citations, and developer hooks for tool execution. These features can help research teams build analysis assistants with more inspectable source references, while the release also changes expectations for tool return types.

commons: a framework for data analysis agents in R and Python

Posit introduces commons, a framework for building self-service data analysis agents on its open-source language-model and chat libraries. It offers a starting point for researcher-facing analysis interfaces; the Python package was still a prerelease beta at announcement.

Decoding the cancer microbiome: multi-omics, AI, and translational opportunities

This review examines how multi-omics data and AI can support cancer microbiome research, emphasizing model interpretation, validation, and biological reliability. It provides a useful planning resource for integrated microbiome studies while distinguishing research opportunities from established clinical applications.

When models choose metrics: hidden geometry in computational biology

This perspective explains how statistical models imply distance measures and when familiar transformations, including RNA-seq variance stabilization, approximate those distances. It encourages explicit metric choices and sensitivity checks when dependence, nuisance variation, or model misspecification make a standard distance unreliable.

Evolutionary rescue model explores strategies for cancer cell extinction

An evolutionary simulation study compares sequential two-strike treatment with combination treatment and examines how switch timing and cross-resistance affect tumor-cell extinction. The results suggest hypotheses for treatment-scheduling research, but are computational findings rather than evidence of patient benefit.

Shiny for Python 1.8 adds in-memory server testing

Shiny for Python 1.8 introduces browser-free testing of reactive server logic, support for complete HTML documents as app interfaces, and reconnection to live sessions. These additions make it easier to validate and maintain interactive research dashboards.

Dreamlet enables cohort-scale single-cell differential expression analysis

Dreamlet uses precision-weighted pseudobulk linear mixed models to test cell-type-specific expression differences across subjects while accommodating complex study designs. The paper evaluates computational and statistical performance on large datasets, offering a practical approach for cohort-scale single-cell studies.

ggsql 0.5.0 reaches beta with expanded database readers and writers

ggsql 0.5.0 advances to beta and expands its reader and writer architecture for working with database-backed visualizations. Support for ADBC alongside existing database interfaces broadens options for plotting research data close to where it is stored.

Single-cell phylogenetics explores non-small cell lung cancer evolution

Researchers apply phylogenetic and phylodynamic methods to exome data from 351 tumor cells across 11 patients to investigate lung cancer evolution. The inferred trajectories motivate a multi-phase evolutionary hypothesis, with the small cohort and focus on primary and early-stage tumors limiting generalization.

BioC2026 conference recap and community resources

This September recap summarizes the August BioC2026 meeting, including research talks, package demonstrations, conference materials, and post-conference activities. It offers a route to learning resources and community developments relevant to reproducible computational biology.

scLS screens genes for pseudotime-associated expression changes

September coverage highlights scLS, a July method that uses Lomb–Scargle spectra to screen for dynamic and condition-dependent expression patterns along pseudotime. It can prioritize genes without explicit branch assignments, but does not localize changes to individual lineages and should be complemented by lineage-aware analysis.

Single-cell approaches connect cancer genotypes with cell states

This review examines how joint measurements of genetic alterations and cellular phenotypes can reveal cancer clonal evolution. It provides a framework for combining single-cell and phylogenetic methods to study mutant-cell behavior and potential vulnerabilities, rather than evidence of an established clinical test.

qMAP measures differential RNA fragmentation beyond abundance

September coverage revisits qMAP, a July computational framework for comparing fragmentation patterns along parental RNAs and identifying the small RNA species driving those differences. Its developmental and disease examples suggest an additional analysis dimension beyond abundance, while disease-classification findings remain research results.

Sequencing strategy affects estimates of A-to-I RNA editing

This September post covers a July study comparing A-to-I editing estimates from short-read RNA-seq and long-read cDNA sequencing in human cell lines. Short reads tended to yield lower estimates, with alignment of heavily edited reads contributing to the discrepancy; the result motivates platform-aware validation rather than assuming measurements are interchangeable.

ResolVI addresses molecule misassignment in spatial transcriptomics

ResolVI models molecule misassignment, background contamination, and batch effects in spatial transcriptomics to improve downstream expression analysis. Available through scvi-tools, it supports integrated cell-state analysis, although correction quality still depends on the starting segmentation and available validation data.

APALORD analyzes alternative polyadenylation from long RNA reads

September coverage highlights the August APALORD framework for detecting polyadenylation sites and comparing RNA cleavage-site distributions between conditions. Applications to human neuronal differentiation and Drosophila demonstrate how long reads can expose RNA-ending changes and expand incomplete annotations.

DeOPUS estimates cell-type composition from bulk RNA-seq

DeOPUS combines shrinkage, power transformations, and constrained unmixing to estimate cell-type proportions from bulk RNA-seq using reference profiles. Its multi-tissue benchmarks offer a tool to evaluate for cohort-scale deconvolution, with applicability dependent on reference quality and the tissues represented.

ComboBatch benchmarks bulk RNA-seq harmonization in lymphoma

This preprint evaluates harmonization strategies across 88 B-cell lymphoma cohorts and provides the ComboBatch pipeline for comparing batch-removal and imputation choices. Its results favor different methods for mixed-platform and RNA-seq-only data, offering practical guidance whose generalizability beyond the evaluated cohorts still needs assessment.

scAtlasPy supports disk-based analysis of large single-cell atlases

This preprint introduces scAtlasPy, which keeps data on disk to reduce the memory requirements of atlas-scale single-cell analysis. The authors report large-scale processing and minibatch-retrieval benchmarks, making it a candidate for teams whose datasets exceed workstation memory; these performance claims have not been independently checked here.

spaCraft estimates sample-size requirements for spatial transcriptomics

This preprint presents spaCraft, which uses replicated pilot data to estimate power for spatial differential-expression and composition endpoints. Its simulations repeat domain recovery to account for clustering uncertainty, offering study-planning guidance conditional on the pilot data and analysis model.

Post-selection bias can affect phenotype testing in single-cell studies

This preprint studies the bias introduced when the same expression data are used to define cell groups and test sample-level phenotype differences. Simulations identify settings with inflated false discoveries and evaluate correction and diagnostic strategies, motivating checks for phenotype imbalance before interpreting differential expression.

Treehouse Splice Compendium provides pediatric cancer splicing profiles

This preprint describes uniformly processed alternative-splicing profiles from 1,152 TARGET pediatric cancer samples and 1,098 GTEx comparator samples. A reproducible workflow accompanies the Treehouse Splice Compendium, supporting exploratory pediatric cancer splicing analyses while requiring care when comparing tumor and non-diseased cohorts.

MINT combines histology and spatial measurements to infer cell transcriptomes

This preprint introduces MINT, which combines paired histology with sample-specific spatial measurements to infer cell-resolved expression without an external single-cell reference. Evaluations include spatial-platform comparisons and lung adenocarcinoma tissue, but inferred expression should remain distinguishable from directly measured transcripts.

MERFISHEYES enables browser-based spatial transcriptomics exploration

This preprint describes MERFISHEYES, a browser platform for viewing and sharing single-cell and single-molecule spatial transcriptomics datasets. It supports marker exploration, subcellular localization, and cross-dataset comparisons, with demonstrations on Brain Image Library datasets; its reported scalability was not independently tested here.

BEACON improves sample demultiplexing for single-cell RNA-seq

This preprint introduces BEACON, which learns background barcode counts to improve sample assignment in multiplexed single-cell experiments. The authors also extend the approach to protein-transcriptome measurements, suggesting a tool to evaluate for reducing ambiguous assignments and recovering protein signals.

Benchmark compares four long-read single-nucleus RNA-seq workflows

This preprint compares four commercial library workflows using Oxford Nanopore sequencing of a standardized multi-species nuclei sample. Differences in transcript coverage, isoform recovery, and yield provide study-design guidance, although rankings depend on the tested sample and sequencing setup.

RIPIN explores RNA-aware preservation for spatial transcriptomics

This preprint investigates how tissue RNase activity affects spatial transcriptomics and introduces RIPIN, a preservation approach combining rapid RNase inhibition with chemical inactivation. MERFISH experiments across human and mouse tissues support evaluating RNA-aware processing, without establishing equivalent performance for every spatial assay.

Bramble projects genomic alignments for transcript quantification

This preprint presents Bramble, which converts spliced genomic alignments into transcriptomic coordinates for downstream abundance estimation. Simulations with short and long reads suggest improved quantification when annotations are incomplete; these results remain dependent on the simulated settings and reference quality.

Large single-cell cohorts can still lack power for small expression effects

This preprint uses sex-biased expression across 1,494 donors and three brain cell types to investigate statistical power and reproducibility. Its findings emphasize the joint importance of donor numbers, cell counts, and sequencing depth, while the studied tissues and biological contrast limit direct transfer of its power estimates.

Multi-omic atlas connects gene regulation across 21 adult human tissues

This preprint combines single-nucleus expression and chromatin-accessibility measurements across 21 adult human tissues to map regulatory elements and predict variant effects. The resource supports cross-tissue regulatory analysis, but its four-donor sampling limits population-level generalization.

LIGER2 scales single-cell integration with on-disk datasets

This preprint updates LIGER with parallel factorization and on-demand disk loading to reduce the time and memory costs of integrating large single-cell datasets. It also introduces an embedding-alignment approach intended to preserve biological variation while aligning corresponding cell types; suitability should be evaluated on the intended integration task.

CellDot uses optimal transport to correct spatial transcript assignments

This preprint introduces CellDot, which combines spatial information and reference expression to retain, reassign, or remove individual transcripts in imaging-based spatial data. Tumor-dataset evaluations suggest benefits for cell-state and niche analyses, with correction depending on the reference and assignment assumptions.

HARP provides a community PBMC reference and hierarchical label transfer

This preprint presents HARP, a community-annotated PBMC reference integrating approximately nine million cells from more than 2,600 donors across health and disease. Its scTiger label-transfer framework supports harmonized immune-cell annotation, while the reported research applications do not establish clinical diagnostic performance.

Python September releases fix security issues and move 3.13 to security-only support

Python 3.14.8 and 3.12.15 address security issues involving TLS and archive handling; 3.13.16 is the final full maintenance release of the 3.13 series. This September 30 release cycle matters for research environments that process external files and for planning maintenance of pinned Python versions. Subsequent Python 3.13 releases will contain security fixes only.

renv 1.3.0 hardens Git restoration and improves reproducibility

renv 1.3.0 tightens handling of Git URLs, refs, and commits to prevent crafted package records from triggering unintended commands. It also records resolved Git commits and improves transactional restore retries, helping teams recreate the same R environment more reliably.

uv September updates improve package integrity and environment checks

uv 0.12.18 fixes a Windows wheel-installation path traversal weakness and adds read-only environment checks with JSON output. Related September releases add signed macOS/Windows binaries and strengthen repeated-requirement hash checks and recovery after interrupted project changes. These changes support safer, auditable Python environment management.

RStudio 2026.09 adds split source views and managed Assistant controls

RStudio 2026.09.0 adds horizontal and vertical source-editor splits that share edits while allowing independent navigation. It also adds controls for administrator-managed Posit Assistant installations, helping teams review long analysis scripts and maintain consistent tooling. Separate Workbench-only features should not be assumed available in the open-source IDE.

VS Code 1.136.2 addresses agent and workspace security issues

VS Code 1.136.2 is a security update covering issues in agent network filtering, remote agent connections, workspace restrictions, and related components. Teams using coding agents or external repositories should include this release in their editor security review.

VS Code September updates bring agent sessions into development containers

VS Code 1.138 adds local Dev Container agent sessions and expanded Codex integration; 1.139 extends container sessions to SSH, Tunnel, and WSL hosts. Version 1.140 adds a Copilot harness and enterprise AI controls, while multi-folder sessions and shared worktree folders remain experimental. Together these changes help coding agents use project-specific dependencies across local and remote environments.

DuckDB 1.5.6 fixes analytical query correctness and recovery issues

DuckDB 1.5.6 fixes incorrect results involving Top-N window optimizations, NULL ordering, and timezone state during timestamp parsing. It also addresses duplicate output chunks and failed multi-statement rollback paths, making this maintenance release relevant to reliable SQL-based research analysis.

nf-core/rnaseq 3.27.0 expands screening and restores strandedness handling

nf-core/rnaseq 3.27.0 adds raw or trimmed-read contamination screening and support for prebuilt Bowtie2 rRNA indexes. It restores StringTie strandedness flags and fixes failures involving Azure indexes, NCBI annotations, and kallisto-only runs. The pipeline now requires Nextflow 25.10.4 or newer, which matters when updating reproducible RNA-seq workflows.

Ruff 0.16.8 improves autofix safety and Python compatibility

Ruff 0.16.8 preserves operand order in SIM109 fixes and required parentheses in multiline UP040 conversions, and marks UP040 fixes as unsafe. These changes matter when automated linting edits analysis code, where apparently small rewrites can change behavior; the release also extends Python 3.15 compatibility.

GPT-6 Sol, Luna, and GPT-6.1 Sol arrive in Codex and ChatGPT Work

September brought GPT-6 Sol and Luna, followed by GPT-6.1 Sol, to Codex and ChatGPT Work. Model choices for coding and document workflows depend on rollout, plan, client, and workspace settings; these announcements do not establish availability in Chat.

OpenAI desktop macOS update fixes CVE-2026-100754

The September 25 desktop changelog reports a macOS security fix in version 26.924.20706. This is relevant to teams maintaining ChatGPT/Codex desktop installations; the announcement gives no technical vulnerability details.

Codex removes its MCP server command

The September 5 release removes the codex mcp-server command and standalone binary. Integrations using that interface need revision; external MCP connections remain supported, while app-server is experimental.

September model notices require Codex configuration changes

GPT-5.3-Codex-Spark became unavailable on September 14; a separate notice announced GPT-5.5 retirement from ChatGPT, Work, and Codex for October 14. Teams should update saved model selections; the GPT-5.5 notice excludes the API.

ChatGPT adds shared Spaces and synced Work tasks

The September 29 announcement introduces ChatGPT Space for files, Pages, and collaboration, alongside new Work tasks that sync across desktop, web, and mobile. Local-file operations still require an online connected computer, and existing tasks retain their original mode.

Codex introduces reusable cloud development environments

Codex can prepare and test a development environment, then reuse its filesystem in isolated cloud workspaces. Announced September 29, this supports repeatable coding tasks that continue while the local computer sleeps.

Claude September model releases expand coding and analysis options

Claude Code added Fable 5.1 on September 1, Opus 5.5 on September 22, and Sonnet 5.5 on September 28. Anthropic positions Opus for complex work and Sonnet for faster focused tasks; performance claims remain vendor evaluations. API integrations should check migration requirements, including changes to thinking controls and preserved conversation context.

Claude combines Cowork and chat with document and slide editing

Anthropic began merging Cowork and chat on September 16, initially rolling out to Pro and Max users across web, desktop, and mobile. The announcement also introduced Docs and Slides and in-conversation Design as paid-plan betas, with Enterprise administrator controls. This brings drafting, editing, and longer-running report work into a shared conversation.

Claude Code September updates add evaluations and tighter permission controls

September Claude Code releases add reproducible plugin evaluations and a prompt audit for instructions written for older models. Managed model allow/deny controls and permission fixes support more consistent agent use, while a late-month fix prevents session-resume failures from losing parallel tool-call history. These are grouped workflow and reliability updates rather than separate entries for each daily patch.
